# Mpemba Freezing Experiment

This project investigates the Mpemba effect using a replicated full 2³ factorial design. The experiment tests whether hot water freezes faster than cold water, and examines the main and interaction effects of three factors: initial water temperature, solution density (sugar content), and container material.

## Project Overview

- **Design**: 2-level, 3-factor full factorial experiment (8 runs, 2 replicates each)
- **Goal**: Test the validity of the Mpemba effect and identify significant factors affecting freezing time
- **Tools**: R, Quarto, ggplot2, tidyverse, knitr, FrF2

## Files Included

- **`Codes.Rmd`**: Contains the same code as `Report.Rmd` but without any explanatory text.  
- **`Data.R`**: Script to generate and save observed freezing time data into a CSV file.  
- **`README.md`**: Project overview with experiment description, file list, and license.  
- **`Report.Rmd`**: Rmarkdown source file including all code, results, and written explanations.  
- **`Report.pdf`**: Final formatted report with analysis results, tables, and figures.  
- **`codes_styler.R`**: Optional script to apply consistent styling to R code using `styler`.  
- **`freezing_time_data.csv`**: Experimental dataset saved by `Data.R`, containing freezing times.  
- **`mpemba-freezing-experiment.Rproj`**: RStudio project file for managing the working environment.
